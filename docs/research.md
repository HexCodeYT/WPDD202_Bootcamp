# Research and References

## Purpose

The purpose of this project was to develop a multi-page website using HTML, CSS and JavaScript while applying semantic web design principles and interactive functionality.

## Technologies Used

### HTML5

Semantic HTML elements were used to improve readability, accessibility and maintainability. Elements such as header, nav, main, section, article, aside and footer were implemented throughout the project.

### CSS3

CSS was used to create the visual design, layout and styling of the website. Flexbox was used for horizontal alignment of the service cards and contact cards.

### JavaScript

JavaScript was implemented to provide user interaction including:

- Alert button functionality
- Service card zoom controls
- Student table generation
- Contact form validation
- Character counter
- FAQ accordion interaction
