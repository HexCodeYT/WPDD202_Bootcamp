# Skillup Labs Website

## Overview

This project was developed using HTML, CSS and JavaScript as part of the Skillup Labs Web Development Bootcamp assignment.

The website consists of multiple pages:

- Homepage
- Student Marks Page
- Contact Page

## Features

### Homepage

- Semantic HTML structure
- Hero section
- About section
- Click Me JavaScript alert
- Services section
- Service card zoom controls
- Footer

### Student Marks Page

- Dynamic table generation using JavaScript
- Student marks dataset
- Average calculation

### Contact Page

- Contact information cards
- Contact form
- Character counter
- Form validation
- Simulated message submission
- FAQ accordion

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
